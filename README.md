# LINE Seed Webfonts

LINE Seed Sans TH as woff2, mirrored so my sites do not depend on someone else's repo.

## Use

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/<user>/line-seed-webfonts@1.0.0/line-seed-sans-th.css">

Pin the tag. `@main` moves under you.

## Weights

100 Thin / 400 Regular / 700 Bold / 800 ExtraBold / 900 Black
